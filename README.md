
# Amazon-Inspired Website 🛒

A frontend web development project featuring two webpages inspired by Amazon's shopping website. Built using HTML, CSS, and JavaScript to practice webpage design, styling, and frontend development.

## 🌐 Project Pages

### 1. Home Page — `index.html`
- Amazon-inspired shopping homepage layout.
- Product and promotional images.
- Custom styling and visual sections.
- Navigation and shopping-style interface.

### 2. Second Webpage — `web2.html`
- A separate webpage included in the same project.
- Uses the project's frontend styling and visual assets.
- Provides an additional page to explore the website's design.

## ✨ Features

- Two separate HTML webpages.
- CSS-based layouts and styling.
- JavaScript for frontend interactions.
- Images and other visual assets.
- Beginner-friendly frontend project structure.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
singlepage_projects/

├── style2.css

├── normal.js
├── images and other assets
└── New folder/
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser to view the home page.
4. Open `web2.html` to view the second webpage.

You can also use the Live Server extension in VS Code.

## 🎯 Project Objective

To practice HTML, CSS, JavaScript, webpage layouts, and multi-page website development.
